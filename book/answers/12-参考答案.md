# 第 12 章 参考答案

## 练习 1：画三种编排

### 固定流水线

```text
research → outline → design → render
```

research 失败：

- 整条链停在第 1 步；
- 需要自己写"重试 research"或"降级"的分支；
- 下游不会自动知道"上游没完成"。

### Supervisor

```text
Supervisor
  ├─ 调用 research（失败 → 工具返回 ok=false）
  ├─ 决定下一步：再试 research？还是换 outline？
  └─ SubAgentTool 的依赖检查会拒绝"research 没完成就调 outline"
```

research 失败：

- Supervisor 可能重试，也可能选错；
- 依赖检查会挡住"跳过 research"；
- 如果一直选错，`MaxSteps` 兜底；
- 这一轮可能白烧。

### 图

```text
research → outline → design → render
```

research 失败：

- 后面的节点没有可用输入，不能执行；
- Runner 可以重试 research（有上限）；
- 如果进程挂了，checkpoint 能恢复；
- 可以在 research 后加 HITL，让人确认。

## 练习 2：跑一次 L2

```powershell
go run ./cmd/l2
```

观察点：

- Supervisor 调用了哪些工具？
- 每次调用的返回是不是只有 `{ref, summary}`？
- 它有没有试图在文本里复述研究内容？

然后：

```powershell
$env:L2_SKIP_ORDER="1"; go run ./cmd/l2
```

这个注入让 Mock 试图跳过前置角色。预期看到：

- `SubAgentTool` 的依赖检查拒绝调用；
- 错误信息里列出缺失的依赖；
- 模型拿到拒绝结果后，必须重新调度。

这说明：**顺序约束是代码强制的，不是 Prompt 建议的。**

## 练习 3：让一个必需产物无人负责

在 `cmd/l2` 的 `Required` 里加：

```go
schema.Kind("video")
```

`NewSupervisor` 会在构造期返回：

```text
supervisor: 必需产物 "video" 没有任何角色负责产出
```

这就是构造期校验的价值：配置错误在启动时暴露，而不是跑到一半才发现"这个任务永远不可能完成"。

## 练习 4：Supervisor 提前停止

如果 Mock 只调用 `research` 就说"完成了"：

- `Result.Complete()` 返回 false；
- `Missing` 里包含 `outline`、`design`、`render`（以及任何其他必需 Kind）；
- 下一轮的 `reminderPrompt` 会说"以下必需产物还没有产出：..."；
- 外层最多跑 `supervisorRounds=3` 轮，然后返回一个不完整的结果。

关键点：模型说"完成"不算数，`Missing/Incomplete/Stale` 才算。

## 练习 5：客服工单系统

推荐：**图 + HITL + checkpoint**，而不是纯 Supervisor。

理由：

- "分类 → 查知识库 / 查订单 / 转人工"是明确的流程分支，适合用图的边表达；
- 所有操作要能审计：图 + checkpoint 能记录每一步的输入、产物、决策；
- 人工可以随时接管：HITL 中断是图的原生能力；
- 分类节点内部可以用 LLM（甚至可以用 Supervisor 做子图），但外层流程由代码保证。

需要补的能力：

- 工单状态持久化（checkpoint）；
- 人工中断与恢复（HITL）；
- 权限与审计日志；
- 对"转人工"分支的超时与 SLA。

如果流程非常开放（每天都有新类型的工单），可以把"分类"做成 Supervisor，但**审计和人工接管仍然需要图/状态机来兜底**。

## checkpoint 的简要答案

- **谁决定下一步**：流水线是代码写死；Supervisor 是模型；图是依赖推导。
- **为什么子 Agent 包装成工具**：工具调用天然提供"派活 + 结果回灌"，不需要发明 transfer 协议。
- **三件事**：Missing（有没有）、Incomplete（全不全）、Stale（还对不对）。
- **图不需要模型决定顺序**：节点声明 `Needs()`，边由代码推导，Runner 按拓扑序执行。
- **L2 缺三样**：进程级恢复、HITL、节点级幂等/审计。
- **怎么选**：稳定流程用流水线/图；开放任务用 Supervisor；要恢复与审计用图；混合时在图里放 Supervisor 节点。
